# Prompt Builder

Um plugin para criação e gerenciamento de prompts personalizados diretamente pelo painel do WordPress.

## Descrição

O Prompt Builder permite que administradores do WordPress criem, editem e organizem prompts (frases, comandos ou instruções) que podem ser utilizados para alimentar APIs de IA, criar formulários inteligentes ou estruturar fluxos de automação de conteúdo.

Totalmente integrado à interface do WordPress, oferece um painel simples e intuitivo, com suporte à internacionalização.

## Funcionalidades

- Interface amigável para gerenciar prompts
- Criação e edição de prompts com título, conteúdo e metadados
- Organização por categorias e tags
- Exportação e importação (planejado)
- Pronto para tradução (.pot incluído)

## Instalação

1. Copie o plugin para a pasta `/wp-content/plugins/prompt-builder`
2. Ative o plugin pelo menu `Plugins` no painel do WordPress.
3. Se preferir, baixe apenas o arquivo `prompt-builder.zip` e utilize a instalador de plugins do WordPress.

## Requisitos

- WordPress 6.5+
- PHP 8.1+
- MariaDB 10.6+
- Docker (ambiente de desenvolvimento recomendado)

## Uso

Após ativar o plugin, um novo menu **Prompt Builder** aparecerá no painel do WordPress. A partir dele, é possível:

- Criar novos prompts com campos personalizados
- Visualizar todos os prompts cadastrados
- Editar e excluir prompts existentes

## Internacionalização

Os arquivos de tradução estão disponíveis na pasta `languages/`.
